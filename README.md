<details>
<summary><b>🌳 땅따먹기</b> — 안산문화재단 Blooming Nature 전시</summary>
<br>

관객이 버튼을 누르면 자연이 파괴되고, 손을 떼면 도시가 자연에 잠식되는 인터랙티브 미디어아트입니다.

- **구성:** Arduino Uno 버튼 입력에 따라 글리치 효과와 함께 식물이 소멸하고, 버튼을 떼면 건물이 이끼에 잠식되며 사라집니다.
- **회고:** 입력이 반복되던 문제를 버튼 입력을 상태 변화로 관리해 해결했습니다. 장비를 세트로 묶고 장시간 실행을 점검하면서, 전시에서는 운영 안정성이 중요하다는 점을 배웠습니다.
- [영상](https://drive.google.com/file/d/1WXLNve88IDl6ERJrXHFr51y52tRxB5Qd/view?usp=sharing)

</details>

<summary><b>🏝️ 섬의 이야기</b> — 인천아트플랫폼 '담다' 전시</summary>
<br>

강화도 선사시대 유물을 주제로 한 프로젝션 매핑 작품으로, '자연 속 고고학'을 표현했습니다.

- **구성:** 사다리꼴 구조물의 각 면을 Resolume Arena로 매핑하고, 측면 영상으로 땅속으로 들어가는 듯한 착시를 연출했습니다.
- **회고:** 제작 시간이 하루뿐이어서 핵심 메시지와 착시 연출에 집중했습니다. 촉박할수록 제작 범위와 우선순위를 명확히 정해야 한다는 점을 배웠습니다.

<details>
<summary><b>🌠 LastNight</b> — 웨이브 생존 좀비 TPS</summary>
<br>

바리케이드를 설치하고 아이템을 얻으러 밖으로 나가며 웨이브를 버티는 좀비 TPS입니다.

- **구성:** 웨이브가 쌓일수록 난이도가 오르고, 5웨이브마다 무기 교체, 10웨이브마다 대규모 공격이 있습니다. 특수 좀비(폭발·탱커·딜러·소환형)는 10% 확률로 등장합니다.
- **회고:** 특수 좀비는 상속과 인터페이스로, 총기는 공통 클래스를 상속해 구현하면서 재사용·확장 설계를 익혔습니다. 반복 플레이 테스트로 밸런스를 검증했습니다.
- [GitHub](https://github.com/SeoSuHyeon1213/LastNight)

</details>
